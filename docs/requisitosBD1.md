# Requisitos do Projeto — Banco de Dados I (BD1)

### 1. Requisitos Técnicos e de Integração
- **Integração:** Integrar o script SQL com Python ou Java.
- **Interface/Menu:** Criar um Menu em que as alterações possam ser feitas no backend e vistas no banco.
- **Operações do Banco (CRUD):** 
  - Executar `INSERT`, `SELECT`, `UPDATE` e `DELETE` para cada uma das tabelas elaboradas.
  - Implementar a possibilidade de busca por atributos (pelo menos um para cada entidade).
  - Implementar pelo menos **3 SELECTs com JOIN** ao total.
- **Arquitetura e Organização:**
  - Separar o código em `Models` e `DAOs` usando pastas/pacotes (não fazer tudo no arquivo principal/`main`).
  - Cada DAO deve apresentar o CRUD específico para funcionamento das classes Model.
- **Script SQL:** Deve possuir consultas `SELECT * FROM tabelas` para mostrar todas as tabelas e registrar as mudanças acontecendo simultaneamente.

---

### 2. O Que Deve Ser Enviado
- **Repositório:** Utilizar o repositório criado na segunda entrega para inserir todo o projeto.
- **Conteúdo da Entrega:**
  - Arquivo `.sql`
  - Pastas com arquivos do backend
- **Atenção:** Arquivos ou entregas incorretas serão desconsiderados!

---

### 3. Diretrizes da Apresentação
- **Tempo Limite:** A apresentação terá tempo limite de **10 minutos**.
- **Infraestrutura:** Se nenhum integrante do grupo tiver computador particular para apresentar, mandar mensagem antes da apresentação, a fim de não atrasar as apresentações dos colegas.
- **Presença e Participação:**
  - Todos os integrantes do grupo devem vir apresentar (haverá pontuação individual de presença).
  - Não há necessidade de presença nos dias em que seu grupo não foi sorteado (a presença é computada mediante a entrega do projeto).
- **Prazos:** Não serão aceitas entregas fora do prazo sob nenhuma circunstância (prazo de desenvolvimento de 2 semanas).
- **Foco da Apresentação:** Não há necessidade de mostrar o código, apenas o funcionamento do sistema e as mudanças refletidas no SQL.
