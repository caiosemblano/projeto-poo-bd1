## C06 — Programação Orientada a Objetos com Java (POO)

**Projeto Final**  
**Professor:** Flávio Henrique Madureira Bergamini  

---

### Visão Geral do Projeto
Projeto prático final para a disciplina de C06. Este projeto irá compor a nota da NP2 e deverá ser realizado em grupos de **4 alunos**.

**Tema do Projeto:** O tema é livre. Cada grupo poderá escolher o assunto que desejar para desenvolver o sistema, desde que aplique corretamente os conceitos estudados em aula.

### Diretrizes de Desenvolvimento (Conceitos POO)
O objetivo é desenvolver um projeto em Java utilizando os principais conceitos de POO, como por exemplo:
- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Composição/Associação
- Métodos e atributos
- Organização do código

---

### Apresentação
- Cada grupo terá **20 minutos** para apresentar o projeto.
- As apresentações acontecerão entre os dias **15/06 e 24/06**.
- Cada grupo apresentará **somente para o professor**; os demais integrantes de outros grupos poderão chegar em seus respectivos horários e datas.

**O que é esperado na apresentação?**  
Durante a apresentação, o grupo deverá mostrar:
- Tema escolhido
- Funcionamento do sistema
- Estrutura das classes
- Conceitos de POO aplicados
- Código-fonte principal
- Participação dos integrantes

---

### Entrega e Observações
**Entrega:** O código do projeto deverá ser entregue exclusivamente pelo GitHub.

**Observações Importantes:**
- Todos os integrantes devem participar.
- O projeto deve estar funcionando no dia da apresentação.
- Criatividade, organização e aplicação correta dos conceitos serão considerados na avaliação.
- Deverão enviar a lista dos integrantes até o dia **04/05** para que possa ser divulgada a ordem das apresentações.
